# Plan: N_mineraal berekening met na.rm

## Probleem
De huidige optelling met `+` geeft `NA` zodra één van de drie kolommen `NA` is.

## Oplossing: rowSums met na.rm = TRUE
`rowSums(.SD, na.rm = TRUE)` negeert NA-waarden en telt alleen de beschikbare waarden op.

## Twee varianten

### Variant A — alle NA → 0 (simpel)
Als alle drie kolommen NA zijn, geeft rowSums een 0 terug.

```r
abio_proj[, N_mineraal_OR_25 := rowSums(.SD, na.rm = TRUE),
          .SDcols = c("N-NH4_CC_mg/kg_OR_25", "N-NO3_CC_mg/kg_OR_25", "N-NO2_CC_mg/kg_OR_25")]

abio_proj[, N_mineraal_SB := rowSums(.SD, na.rm = TRUE),
          .SDcols = c("N-NH4_CC_mg/kg_SB", "N-NO3_CC_mg/kg_SB", "N-NO2_CC_mg/kg_SB")]

abio_proj[, N_mineraal_OR_50 := rowSums(.SD, na.rm = TRUE),
          .SDcols = c("N-NH4_CC_mg/kg_OR_50", "N-NO3_CC_mg/kg_OR_50", "N-NO2_CC_mg/kg_OR_50")]
```

### Variant B — alle NA → NA (veiliger)
Als alle drie kolommen NA zijn, blijft het resultaat NA.

```r
abio_proj[, N_mineraal_OR_25 := {
  s <- rowSums(.SD, na.rm = TRUE)
  ifelse(rowSums(!is.na(.SD)) == 0, NA_real_, s)
}, .SDcols = c("N-NH4_CC_mg/kg_OR_25", "N-NO3_CC_mg/kg_OR_25", "N-NO2_CC_mg/kg_OR_25")]

abio_proj[, N_mineraal_SB := {
  s <- rowSums(.SD, na.rm = TRUE)
  ifelse(rowSums(!is.na(.SD)) == 0, NA_real_, s)
}, .SDcols = c("N-NH4_CC_mg/kg_SB", "N-NO3_CC_mg/kg_SB", "N-NO2_CC_mg/kg_SB")]

abio_proj[, N_mineraal_OR_50 := {
  s <- rowSums(.SD, na.rm = TRUE)
  ifelse(rowSums(!is.na(.SD)) == 0, NA_real_, s)
}, .SDcols = c("N-NH4_CC_mg/kg_OR_50", "N-NO3_CC_mg/kg_OR_50", "N-NO2_CC_mg/kg_OR_50")]
```
