# Plan: Kantelpunten in ALE-curves per target

## Doel
Automatisch omslagpunten / kantelpunten detecteren in de ALE-curves van de XGBoost-modellen en deze visueel markeren — voor alle targets en hun top-predictoren.

## Aanpak

### Wat is een kantelpunt in een ALE-curve?
Een kantelpunt is een x-waarde waar de ALE-curve van richting verandert (van stijgend naar dalend of vice versa), of waar de helling het sterkst verandert (inflectiepunt). Dit zijn ecologisch relevante drempelwaarden.

We detecteren twee typen:
1. **Lokale extrema** (min/max): punten waar de afgeleide van teken wisselt → "omslagpunten" (bv. optimum of drempelwaarde)
2. **Sterkste helling**: het punt met de grootste absolute verandering per eenheid x → "kantelpunt"

### Detectiemethode
Voor elke ALE-curve (vector `x_values`, `ale_effects`):

```r
detect_tipping_points <- function(x, y, min_effect_range = 0.01) {
  # 1. Lokale extrema via tekenwissel van diff(y)
  dy <- diff(y)
  sign_changes <- which(diff(sign(dy)) != 0) + 1  # index in y
  
  # 2. Sterkste helling (max abs verandering per stap)
  dy_per_dx <- dy / diff(x)
  steepest_idx <- which.max(abs(dy_per_dx)) + 1
  
  # Filter: alleen rapporteren als effect_range groot genoeg
  effect_range <- diff(range(y, na.rm = TRUE))
  if (effect_range < min_effect_range) return(NULL)
  
  list(
    local_extrema_x = x[sign_changes],
    local_extrema_y = y[sign_changes],
    steepest_x = x[steepest_idx],
    steepest_y = y[steepest_idx]
  )
}
```

### Visualisatie
Nieuwe functie `create_ale_tipping_plots()` die:
- Per target: facet-grid met top-5 predictoren (zoals bestaande `ALE_top5_*.png`)
- Per subplot: ALE-lijn + echte data (grijs) + mediane referentielijn
- **Nieuw**: 
  - Verticale stippellijnen bij kantelpunten (oranje = lokaal extremum, paars = steilste helling)
  - Annotatie met x-waarde van het kantelpunt (bijv. "Kantelpunt: 0.42 m")
- Opslaan als `ALE_tipping_points_<target>.png`
